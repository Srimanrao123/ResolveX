# ReturnGuard AI — 3-Minute Demo Plan

## Opening (20 seconds)

“Small e-commerce sellers either inspect every return manually or approve everything. ReturnGuard is an AI return department that investigates the case before a decision is made.”

## Demo sequence

1. **Customer: quick resolution** — Open a delivered shirt order. Enter “It is too tight.” Show the return being automatically approved because the item is within policy and the history is normal.
2. **Customer: investigation** — Open the shoe order. Enter a damage claim and upload the pre-seeded unclear image. Show “Under seller review,” not an automatic refund.
3. **Seller: explainability** — Open the same case in the seller portal. Point out: policy eligible, previous damage claims, unclear evidence, risk level, and Claude-generated case summary.
4. **Seller: control** — Approve or reject the review case. Emphasize that the seller makes the final call on exceptions.
5. **Learn** — Show the size-related return insight for a product and explain that returns improve the store over time.

## One-sentence close

“ReturnGuard resolves routine returns, protects sellers from risky exceptions, and turns return data into product improvements.”

## Judge-facing points

- It is agentic because it gathers context, checks rules, identifies missing evidence, assesses risk, chooses an action, and escalates exceptions.
- It is safe because policy and financial decisions are deterministic; Claude helps interpret language and evidence and explain the result.
- It is practical because the seller only reviews the cases that need human judgment.
